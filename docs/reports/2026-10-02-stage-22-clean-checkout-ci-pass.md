## 9. Root causes and fixes

### 9.1 Stage 14 — already hermetic; no change needed
`section_artifacts()` already calls `build_artifacts_into()`, which runs
`build-plugins-zip.sh` and `build-theme-zip.sh` with `BUILD_OUTPUT_DIR` pointing
at a `tempfile.TemporaryDirectory()`. With `dist/` **moved aside** it reports
`324 passed, 0 failed`. The CI failure was already fixed by `133f934`; this
stage verifies rather than repeats the fix.

### 9.2 Stage 13 — ordering already correct; no change needed
`gather_repo_facts()` no longer reads `dist/release.json`. It calls
`build_artifacts()` first and then derives `versions_match_release` from the
record that build emitted — the exact ordering the task asked for. With `dist/`
absent: `808 passed, 0 failed`.

### 9.3 The two NEW defects

**(a) `i18n_freshness` was red — fixed by regenerating the catalogue.**
`133f934` edited `template-parts/event-card.php` but did not regenerate
`conexao-br-irlanda.pot`. The gate compares **git commit times** (deliberately,
not mtime, so it survives a clone), so the catalogue was 17 902 s "older" than
its source. Regenerated with the documented tool. The gate is fails-closed by
design: the entry in `tests/baseline/permanent-gates.json` is reporting-only and
never excuses a violation.

**(b) The bilingual fixture was nondeterministic — fixed at the root.**
`test-guide-en-translation.php` failed in run 1 and passed in run 2 with
identical code. Cause: the EN half inherited the PT date only via
`if ( ! empty( $pt_fields['date'] ) )`, and the `como-tirar-o-pps-number` guide
pins no `date` in the dataset. WordPress therefore stamped `now` on the PT
insert and again, seconds later, on the EN insert. The fix reads the PT record
**back after it is stored** and gives the EN half that exact value, making the
invariant unconditional — which is what the adjacent comment already claimed.

### 9.4 The event single URL — investigated, deliberately unchanged
The task stated the individual route is `/event/{slug}/`. The runtime disagrees:

```

get_permalink = http://localhost:8080/eventos/<slug>/
GET /eventos/<slug>/  -> 200
GET /event/<slug>/    -> 301  Location: /eventos/<slug>/
```

`conexao-data-model.php` registers the `event` type with
`rewrite.slug = 'eventos'`. **Changing the suite to `/event/` would have broken
