repository, and the translation architecture was consolidated onto the single

conexao-translation-rollout -> conexao-en-translation -> manual workflow -> Polylang

## 2. Scope NOT completed

One item was **not** achieved, and it is the substantive caveat of this stage:

> **The retired `job` rollout's authored manifest is not represented by any
> active stage.** Its single authored row now survives only in Git history.

`job` is a B2 post type; none of the seven supported stages carries job
*records* (`en-jobs-page` is the Jobs **landing page**), and the retired stage
explicitly declared `'allow_remove' => false` because its EN jobs carry a
verbatim `_job_*` meta layer and shared media that the manifest alone does not
reconstruct. I stopped and asked before deleting; the operator authorised
retiring the dataset with the plugin. This is recorded in
`docs/plugins/conexao-job-translation.md`, in `docs/architecture.md`, and as an
explicit `[GAP ]` line in the proof output — never as a pass.

Also not done (out of scope by instruction): no production action, no Flutter or
mobile repository access, no PT content change, no B1/B2 or Polylang change.

## 16. Rollback / recovery

Fully reversible — the change is a single commit with no content, no production
and no state migration.

```bash
git revert eeff280d6914d9b0fdfa7559cacba0fd59fba854   # or:
git reset --hard 1e09ee276aff0638fd2bad47d290d08efa1f83a5
```

After a revert, re-run `php scripts/generate-registry-docs.php --write` to
restore the 15-entry registry regions.

What rollback does **not** cover: nothing. No content, Polylang state, option or
production artifact was touched, so there is nothing to reverse beyond the
repository itself. Docker bind mounts may leave empty `conexao-*-translation`
directories behind — `docker compose down && rmdir` them; the registry gate
fails closed on such an orphan, so it cannot be missed.

To recover the retired `job` manifest specifically:

```bash
git show 1e09ee276aff0638fd2bad47d290d08efa1f83a5:wp-content/plugins/conexao-job-translation/includes/translation-map.php
```
