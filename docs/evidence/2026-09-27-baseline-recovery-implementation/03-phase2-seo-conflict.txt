## DECISION
  Default recovery target = the verified b47d098 modular inc/seo/ architecture.
  inc/seo.php is REMOVED from the recovered runtime. Rationale:
    (a) 23 duplicate function names => fatal redeclaration if both load;
    (b) it adds 0 new functions (strict subset), so nothing is lost by removing it;
    (c) the assessment labels it the one refactor-shaped element but INCOMPLETE (drops 4 fns
        incl. conexao_seo_hreflang, conexao_seo_in_language, conexao_seo_missing_translation_redirect,
        conexao_seo_disable_jetpack_og_on_b2) which carry the B2/Polylang/hreflang contract;
    (d) no merge attempted: merging would re-introduce a second SEO implementation and
        would violate the "reuse, do not reinvent" rule in AGENTS.md.
