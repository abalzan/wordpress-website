## NOTE ON THE ZIP TIMESTAMP (recorded, not hidden)

The build stamps each archive with the NEWEST source mtime
(scripts/lib/zip-build.sh), so a ZIP's sha256 legitimately changes when a file
is edited, even when its CONTENT does not. Two builds of an UNCHANGED tree are
byte-identical (c1 vs c2: 10/10); a build after an edit differs by design.
