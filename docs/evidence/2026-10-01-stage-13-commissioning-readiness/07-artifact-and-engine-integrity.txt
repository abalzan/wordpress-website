## Artifact content scans

  Secret-shaped values in either artifact                     = 0
  tests/ files shipped                                        = 0
  local / Docker-only files shipped                           = 0

The secret scan is ASSIGNMENT-based, not shape-based: a secret-named variable
bound to a non-empty literal. A shape-only rule matches English prose ("code
path from this" is four four-letter words) and would report a false positive on
the repository's own docblocks, training an operator to ignore the gate.
Documentation placeholders (your-app-password, <...>, xxxx) and constants that
hold the NAME of a secret (CREDENTIAL_ENV, NONCE_ACTION) are excluded by
documented, narrow rules; the credential VALUE shapes are still checked over
the whole text, so the exclusion cannot hide a real key.
