  EN sitemap must NOT contain the B1 URL:
    /sitemap.xml status 200, 611654 bytes, 0 PHP errors
    occurrences of "en/empregos" : 0      <- B1 URL absent from the sitemap (correct)
    occurrences of the PT URL    : 1      <- PT canonical present (correct)

  NOTE: /en/sitemap.xml returns 404. This is BY DESIGN, not a regression: the theme
  serves ONE sitemap. inc/seo/sitemap.php:40 only serves /sitemap.xml and

  avoid competing sitemaps. The EN URLs are carried inside that single sitemap as
  xhtml:link alternates.

## Documented content limitations (NOT implementation regressions)
  /en/guias/page/2/ -> 404
    The local dataset contains 0 EN guide records (48 PT guides, 0 EN). With no EN
    guides there is no page 2. This is a DATA limitation. No EN guide content was
    fabricated to green it, and routing was not changed to conceal it.
    It is the documented cause of the one failing HTTP acceptance suite:
      [FAIL] tests/acceptance/verify-guides-en-http.py
        - en-guides-page-2 /en/guias/page/2/ -- status 404, expected 200
        - an EN guide link is discoverable in /en/guias/
    Both assertions are consequences of the same missing EN content.

  /en/empregos/ -> 302 to PT (B1, by design)
    Preserved exactly as established. NOT an implementation regression.
