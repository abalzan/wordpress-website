== SCOPE OF THE GENERATOR DEFECT (scripts/i18n-make-pot.sh:514) ==

The generator builds a file list on stdin and pipes it to:
    printf "%s" "$file_list" | xgettext ... --files-from=- --output="$out_pot" </dev/null

xgettext reads the file list from STDIN. The trailing </dev/null replaces STDIN
with /dev/null, so xgettext receives an EMPTY list, extracts nothing, never creates
--output, and still exits 0. The old catalogue is left untouched, then
add_header_strings() appends 5 style.css blocks AGAIN -> duplicate msgids.
