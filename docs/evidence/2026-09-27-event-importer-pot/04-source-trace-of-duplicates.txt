-- CONCLUSION --
The strings are NOT extracted from a gettext call. They are synthesised by
add_header_strings() in scripts/i18n-make-pot.sh from the plugin docblock, which is
what wp i18n make-pot also does for Plugin Name/Description/Version. There is
ONE logical msgid per string, so the duplication is an artefact of the broken
generator run 88e8ec0, not a source defect and not a context problem.
