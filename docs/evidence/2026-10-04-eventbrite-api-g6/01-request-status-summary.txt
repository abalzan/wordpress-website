C. COVERAGE — THE DECIDING MEASUREMENT
====================================================================
Walk summaries (bounded samples; see cork-sample.json etc. for raw ids):

  County    Pages walked  Events  distinct organizers  declared object_count
  Cork      5 of 49        100     36                  1553
  Dublin    5 of 49        100     74                  5173
  Carlow    3 of 49         60     51                  4780

Reading:
  - The public county listing is a MULTI-ORGANIZER aggregate. Cork's first 100
    events already span 36 distinct Eventbrite organizations.
  - The official API's only documented event collection is organization-scoped
    (GET /organizations/{organization_id}/events/), and organization discovery
    is per-user (GET /users/{user_id}/organizations/). There is no documented
    way to ask the API "which organizations have events in Cork?".
  - Therefore a token would have to be a member of tens to hundreds of
    independent third-party organizations to reproduce a county listing. That is
    not an integration problem; it is a different ownership model.

The 49-page cap applies to every county: page_count is 49 and object_count
exceeds 1000, so the current scraper itself does NOT enumerate the full county
listing either. Both paths are truncated; the API path is truncated
differently (by ownership) rather than by page cap.
